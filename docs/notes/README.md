# docs/notes/ — Personal Notes

Scratch notes, research summaries, and working documents.

---

## Naming Convention

```
YYYY-MM-DD-topic.md          Daily notes (e.g. 2026-03-17-mcp-research.md)
topic-name.md                Reference notes (e.g. snapdragon-benchmarks.md)
```

---

## Suggested Note Categories

| Prefix | Use |
|--------|-----|
| `research-` | Technology research notes |
| `issue-` | Debugging sessions and resolutions |
| `idea-` | Feature ideas and proposals |
| `log-` | Daily/weekly work logs |
